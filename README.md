# Processos Jurídicos

## 💡 About

**Processos Jurídicos** is a modernized application that replaces the previous SharePoint 2013–based system, addressing its performance, maintainability, and security limitations.

The new version was rebuilt using **ASP.NET Core MVC** and **SQL Server**, ensuring a more secure, scalable, and future‑proof platform. Key enhancements include:

- Two‑factor authentication (2FA)  
- Modern development stack  
- Full independence from SharePoint  
- Integrated workflow engine  
- Improved performance and stability  
- Better accessibility and user experience  

---

## 🕰️ History

### **2016 — Version 1.0**  
Developed by the *Direção de Análise e Gestão de Informação (DAGI)*, the first version ran on **SharePoint 2013** with **Nintex Workflows**, supporting around **3000 processes** over its lifetime.

### **2025 — Version 2.0**  
In May 2025, DAGI initiated a full system redevelopment, migrating all data to a modern architecture based on **ASP.NET Core MVC** and **SQL Server**.  
This redesign focused on security, performance, and long‑term maintainability, while preserving the functional model familiar to users.

📌 **Production Release:** *14 November 2025*
